How to order through SuperBuy

  1. Open a CAFANS product below and select Buy Link, then choose Superbuy from the agent menu.
  2. Check that the agent page opens the intended item. Compare the colour, size and quantity with the seller listing, and confirm the price for that variant.
  3. If the agent link fails, copy the original Weidian listing URL from the CAFANS product page and check whether SuperBuy accepts it.

Warehouse QC checklist

Save the original listing and your chosen variant. If warehouse inspection photos are available, use them to check the item before approving shipment.

Shoes

Compare the size labels on both shoes. If fit is uncertain, ask for an insole measurement and compare it with a pair that fits.

T-shirts & sweatshirts

Compare laid-flat chest width and body length with a garment you own. Check artwork placement, stitching and label size.

Jackets

Check sleeve length and shoulder width, then inspect the closures and lining. Review the return deadline before requesting a replacement.

Estimate landed cost

Compare quotes using the same destination and packed dimensions. Check whether the shipping line bills by actual weight or volumetric weight, and whether its quote includes any charges you’ve entered separately.

SuperBuy spreadsheet FAQ

What is a SuperBuy spreadsheet?

It is a list of product links you can browse and check for ordering through SuperBuy. This independent guide uses product listings from CAFANS.

Why does the price change after I choose a size or colour?

Sellers can price variants differently. Check the selected variant in the agent interface and use that amount in your budget.

Is the catalogue price the amount I will pay?

The table shows item prices. Add domestic freight, international shipping and any applicable fees or import charges to estimate what you’ll pay.
